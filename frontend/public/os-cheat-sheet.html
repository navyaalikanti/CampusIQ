1. CPU Scheduling & Formulas

Key Metrics

  • Turnaround Time (TAT) = Completion Time - Arrival Time
  • Waiting Time (WT) = TAT - Burst Time
  • Response Time = First Run Time - Arrival Time

Algorithms

  • FCFS: Non-preemptive, suffers from Convoy Effect.
  • SJF / SRTF: Optimal, minimum average waiting time. Impossible to predict exact burst times.
  • Round Robin: Time Quantum (TQ). If TQ is too large → FCFS. If too small → high context switch overhead.

2. Deadlock (Must Study)

A set of blocked processes each holding a resource and waiting to acquire a resource held by another process in the set.

4 Necessary Conditions (Coffman Conditions):
  1. Mutual Exclusion: At least one resource must be non-shareable.
  2. Hold and Wait: Holding one, waiting for another.
  3. No Preemption: Resources cannot be forcibly taken.
  4. Circular Wait: P0 waits for P1, P1 waits for P2... Pn waits for P0.

Banker's Algorithm: Need = Max - Allocation. System is safe if a valid safe sequence exists.

3. Synchronization & Semaphores

Semaphore: An integer variable accessed via wait(S) (P) and signal(S) (V).

  • Mutex: Binary semaphore (0 or 1).
  • Producer-Consumer Problem: Needs 3 semaphores: mutex (1), full (0), empty (N).

4. Memory Management (Paging & Segmentation)

  • Paging: Divides physical memory into fixed-sized blocks (Frames) and logical memory into blocks of the same size (Pages). Solves External Fragmentation, suffers from Internal Fragmentation.
  • Translation Lookaside Buffer (TLB): High-speed hardware cache used to speed up logical-to-physical address translation.
    Effective Access Time = Hit_Ratio * (TLB + Mem) + (1-Hit_Ratio) * (TLB + 2*Mem)
  • Segmentation: Variable-sized blocks representing logical segments (code, data, stack).

5. Page Replacement & Virtual Memory

Virtual Memory: Separation of logical memory from physical memory, allowing execution of processes larger than physical memory.

Algorithm Concept Issue
FIFO First In, First Out Belady's Anomaly
LRU Least Recently Used Needs hardware support
Optimal Replaces page not used for longest time in future Impossible to implement

Thrashing: High paging activity. Process spends more time paging than executing. CPU utilization drops drastically.

6. Disk Scheduling Formulas

  • Seek Time: Moving disk arm to target cylinder.
  • Rotational Latency: Waiting for correct sector to spin under head.
  • FCFS: Process in order of arrival.
  • SSTF: Shortest Seek Time First (closest request).
  • SCAN / C-SCAN / LOOK: Elevator algorithms moving across disk.
