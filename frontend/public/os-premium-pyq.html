2. Deadlock Standard Answers

Q2. Define Deadlock. Explain Banker's Algorithm for Deadlock Avoidance with a suitable example. (10M) Sure Shot Faculty Favorite

Definition: A deadlock is a state where a set of processes are blocked because each process is holding a resource and waiting for another resource acquired by some other process.

Banker's Algorithm: It checks whether granting a resource request will leave the system in a Safe State. It relies on four matrices: Allocation, Max, Available, and Need.

Need Matrix Calculation: Need[i][j] = Max[i][j] - Allocation[i][j]

3. Synchronization & Semaphores

Q3. Explain the Reader-Writer synchronization problem and provide a semaphore-based solution. (5M) Repeated 3 times

Problem Statement: Multiple readers can read simultaneously. However, if a writer is writing to the database, no other writer or reader should be allowed access.

Semaphores used:
- mutex (initialized to 1): Protects the read_count variable.
- wrt (initialized to 1): Ensures mutual exclusion for writers.

4. Memory Management (Paging diagrams)

Q4. Explain Paging hardware. Differentiate it from Segmentation. (10M) High Probability

Paging: Memory management scheme that eliminates the need for contiguous allocation of physical memory. Logical address is divided into a Page Number (p) and Page Offset (d).

+-------+-------+ +------------+ +---------+
| p | d | --> | Page Table | --> | f | d | (Physical Adr)
+-------+-------+ +------------+ +---------+

Differences:
- Paging: Fixed size blocks (Frames). Solves external fragmentation. Suffers from internal fragmentation.
- Segmentation: Variable size blocks (Segments) corresponding to user view. Solves internal fragmentation. Suffers from external fragmentation.

6. Viva Style Short Questions (2M)

  • Q: What is Thrashing? A: A state where the system spends more time paging (swapping pages in/out) than executing processes.
  • Q: What is a PCB? A: Process Control Block, a kernel data structure containing process state, program counter, CPU registers, etc.
  • Q: Define System Call. A: An interface between a user-level program and the operating system kernel.
  • Q: What is the difference between Starvation and Deadlock? A: Deadlock is cyclic waiting where no process proceeds. Starvation is where a process waits indefinitely but other processes continue to execute.
